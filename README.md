# SPRITZ

Tempo-synced curve shaper by [Carbonated Audio](https://carbonatedaudio.com/spritz).

This repository holds the installers only. Grab the latest from **Releases**:

- `SPRITZ-Installer.pkg` - macOS, VST3 + AU + AAX, universal (Apple Silicon + Intel), macOS 11 or later. Needs a license key from your receipt.
- `SPRITZ-Windows-Installer.exe` - Windows 10 and 11, 64-bit VST3. Same license key.
- `SPRITZ-Demo-Installer.pkg` / `SPRITZ-Demo-Windows-Installer.exe` - the free demo: the full plugin, 60 seconds of audio then 10 seconds muted, on a loop.

Support: support@carbonatedaudio.com
